# CineMatch — Java Backend Edition

The original CineMatch HTML/CSS interface is retained. The recommendation calculations now run in a Java 17 + Spring Boot backend.

## Requirements
- Java Development Kit (JDK) 17 or newer
- Apache Maven 3.6+ (or use the Maven wrapper generated by your IDE)
- Internet connection on the first build so Maven can download Spring Boot dependencies

## Run in NetBeans / IntelliJ / VS Code
1. Open the `cinematch` folder as a Maven project.
2. Make sure the project SDK is Java 17 or newer.
3. Run `CineMatchApplication.java`, or open a terminal in this folder and run:

   ```bash
   mvn spring-boot:run
   ```

4. Open `http://localhost:8080` in your browser.

Do not open `index.html` directly using `file://`. The browser must load the site through Spring Boot so the `/api/recommendations` endpoint is available.

## Recommendation API
`POST http://localhost:8080/api/recommendations`

Example JSON:

```json
{
  "mood": "romantic",
  "age": 20,
  "gender": "female",
  "genres": ["Romance", "Drama"],
  "ratings": {"5": 5, "10": 4, "16": 5},
  "shuffle": false
}
```

The API returns up to six recommended movies. The frontend sends the quiz answers to this endpoint and renders the returned results.

## Where the algorithm lives
- `src/main/java/com/cinematch/api/RecommendationService.java` — Java implementation of similarity, neighbor selection, rating prediction, and weighted recommendation scoring.
- `src/main/java/com/cinematch/api/RecommendationController.java` — HTTP endpoint.
- `src/main/resources/data.json` — original CineMatch movie catalogue and sample community viewer ratings, extracted from the supplied project.
- `src/main/resources/static/` — original website files with the recommendation request connected to the Java API.

## Algorithm preserved from the supplied website
1. Calculate profile similarity from age and gender.
2. Calculate taste similarity from shared movie ratings when available.
3. Combine taste and profile similarity using the original 65% / 35% weights (profile similarity alone is used when no shared ratings exist).
4. Select the eight most similar sample viewers.
5. Predict each eligible movie rating using a similarity-weighted average; use 3 when no neighbor rated the movie.
6. Score movies using 60% predicted rating, 25% mood match, and 15% genre match.
7. Optionally add the original random shuffle boost, sort by score, and return the top six.

The sample viewer data is still static, as in the original project. This conversion moves the algorithm to Java; it does not add user accounts or a live ratings database.
